# Backend source exclusions for ColossusX

Modification date: 2026-09-21. Base: Blockscout v10.2.6, commit `90f7dd8e9348123b74dfd23f69ab7da76191a820`. The upstream GPL license and the notices in retained files are preserved.

This prepared source excludes material in three paths:

1. `config/assets/precompiles-arbitrum.json` is an empty JSON array. The upstream preset contained 16 entries, including 15 interfaces identified as BUSL-1.1. This release omits the preset rather than claiming those interfaces are GPL. ColossusX does not use the Arbitrum chain preset. The filename is retained so Dockerfile copies and the preset loader still receive valid JSON; automatic Arbitrum precompile metadata is unavailable in this release.
2. `apps/explorer/test/support/fixture/smart_contract/issue_4758.sol` is omitted. The source declares UNLICENSED and refers to separate usage terms. No permission to republish that fixture is assumed.
3. The `issue 4758` test in `apps/explorer/test/explorer/smart_contract/solidity/verifier_test.exs` is omitted, including its embedded bytecode. The remaining test module is preserved. This excludes one regression case rather than keeping a test that reads a missing fixture.

The separate BSD 3-Clause license is also restored next to the vendored Ace code at `apps/block_scout_web/assets/js/lib/ace/LICENSE`. Its source is the [official Ace v1.4.14 license](https://github.com/ajaxorg/ace/blob/v1.4.14/LICENSE). The three vendored Ace files are unchanged from v9.0.2. This notice applies to the Ace files and does not relicense them as GPL.

The reviewed English edits are also applied to the GPL baseline on 2026-09-21. `apps/block_scout_web/lib/block_scout_web/graphql/schema/scalars.ex` and `apps/explorer/lib/explorer/chain/wei.ex` use the English Wei Dai link label. `apps/explorer/test/explorer/token/metadata_retriever_test.exs` uses English text plus an emoji for the Unicode byte-length fixture and the matching ABI bytes. Each of these three files has a dated modification notice. The assembler verifies the patch and original-file hashes before applying `colossusx/patches/backend-english.patch`; it does not copy later 11.3.1 source files.

`colossusx/patches/backend-license-preparation.json` records the exact original hashes and the transformations. The assembly tool applies those transformations only to the known GPL baseline. It deliberately does not distribute a deletion patch containing the excluded source or bytecode.

The upstream build environment is Elixir 1.19.4, Erlang/OTP 27.3.4.6 and Node.js 20.17.0, as pinned in `.tool-versions`. Elixir 1.17 used by v9.0.2 is not the supported environment for this version. Source exclusions, original-file hashes and the English patch are checked before release assembly. These checks do not replace compiling and testing a backend artifact.

`COLOSSUSX-SOURCE-PROVENANCE.json` records the selected source tree and its modifications. The independent multi-component release also records the deployment backend source mode in its top-level `SOURCE-PROVENANCE.json`. An unmodified upstream image requires the exact upstream source; this prepared tree is not byte-for-byte corresponding source for that image. A backend built from this prepared tree includes the listed exclusions and English edits. Image provenance, build validation, and separately fetched dependency sources/notices must still be retained when redistributing a binary. The assembler itself does not build, deploy or certify a container image.

The dependency lockfile references 188 externally fetched packages, compared with 180 in v9.0.2: nine were added, one was removed, and 54 changed version or source type. `colossusx/patches/backend-dependency-review.json` records all entries and the exact-version metadata review. The 63 new or changed Hex archives were fully downloaded and checked against their outer SHA-256 checksums in `mix.lock`; unchanged package declarations retain the previous exact-version metadata evidence. The nine new packages declare MIT or Apache-2.0. This is metadata evidence rather than a complete audit of all bundled native code.

The previous `quantile_estimator` package is no longer selected. The `prometheus_ex` Git fork is replaced by Hex `prometheus_ex` 5.1.0, whose MIT license text is present in the exact package and recorded in the report. The separate `prometheus_process_collector` Git dependency remains unchanged. `bcrypt_elixir` 3.3.2 also remains unchanged and includes a historical four-clause BSD notice; the prior review retained evidence of the author's advertising-clause waiver, which must be assessed and preserved when preparing a combined binary. The new `ex_eth_bls` 0.1.0 package declares MIT but its exact Hex archive has no top-level license file; its Rust/native dependencies and upstream notice provenance require separate review before binary redistribution. Installed dependency sources or binaries are not bundled by this source assembler. No all-dependencies or combined-binary licensing certification is implied.
